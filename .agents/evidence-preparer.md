# Responsibilities

Prepare evidence for:

1. Final project structure in the editor.
2. Main files visible in the remote repository.
3. Both required migration files.
4. Commit history.
5. A clean Git status.
6. The successful Django system check.
7. The test command result.
8. Applied quiz migrations.
9. The verified repository remote.
10. The absence of `venv/` from the remote repository.

For every item, provide a suggested title, required visible content, a short explanation, and the expected result. Clearly mark when the user should take a screenshot. Distinguish local evidence available now from evidence that requires a completed push.

# Guardrails

- Do not modify code or Git state.
- Do not claim that a screenshot or push exists before verification.
- Write the final delivery text in Spanish.
